Neon Breaker: a neon Breakout game with 6 hand-designed levels, 8 power-up capsules, combo scoring, particles, screen shake and synthesized sound — all in plain static files with no libraries and no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Move with the mouse or ← → / A D, Space to serve and fire, P to pause, M to mute.
